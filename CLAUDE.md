## Workflow: use the installed BMad skills
- Not sure what's next: run `bmad-help`.
- Planning: `bmad-product-brief` -> `bmad-prd` or `bmad-spec` -> `bmad-architecture` -> `bmad-create-epics-and-stories` -> `bmad-sprint-planning`.
- Implementing a feature, story or fix: `bmad-build` (its review includes the PHI/HIPAA check). Ad hoc review: `bmad-code-review`.
- Test strategy and coverage: `bmad-testarch-test-design`, `bmad-testarch-automate`.
- Planning outputs live in `_bmad-output/planning-artifacts/`; BMad customizations in `_bmad/custom/`.
